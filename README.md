# struct8-hcl-modules

Terraform modules published from Struct8 diagrams.

Each folder here was generated by the publish that created it, from the drawing
the author published. Nothing in this repository is written by hand.

## Layout

One folder per module version:

```
modules/<module-name>/<version>/main.tf
```

A diagram that uses a published module addresses that folder directly:

```hcl
module "app" {
  source = "git::https://github.com/Struct8/struct8-hcl-modules.git//modules/s3-site/1.2.0?ref=main"
}
```

## What a version means

A version folder is written once, by the publish that created it, and is never
regenerated. That is what makes the number mean something: an instance pointing
at `1.2.0` gets the Terraform that `1.2.0` produced, and not what today's
generator would produce from the same drawing.

The ref is a branch, not a tag, so what keeps a published folder from changing
is this product refusing to overwrite it — not git. Point at an exact version.
There is no "latest 1.x" here, and asking for one would give you a folder that
can change under a number that cannot.

## Reading a module before using it

`main.tf` is the whole module. Its `variable` blocks are what the caller has to
supply, and its `output` blocks are what the caller can read back. Both were
fixed at publish time: a `variable` that is not there cannot be passed, and an
`output` that is not there cannot be read, however the drawing looks today.
